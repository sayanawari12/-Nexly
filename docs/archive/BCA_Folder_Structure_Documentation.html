13. Codebase Specification Backend Structure

13.2 Backend Directory Structure (`backend/src/`)

The backend architecture uses modular domain-driven TypeScript layers with Prisma ORM, Express routers, and BullMQ execution queues.

backend/src/
├── config/                              # Server Environment & DB Setup
│   ├── app.config.ts                    # Express App Port, CORS & Security Config
│   ├── auth.config.ts                   # JWT Secret, Expiration & Cookie Flags
│   ├── database.ts                     # Prisma Client Connection Pool Config
│   ├── logger.config.ts                 # Pino Logger Settings
│   └── queue.config.ts                  # Redis BullMQ Connection Credentials
├── middleware/                          # Global Express Request Handlers
│   ├── error-handler.middleware.ts      # Global Exception & Prisma Error Guard
│   ├── maintenance.middleware.ts        # System Emergency Maintenance Interceptor
│   └── request-context.middleware.ts    # Unique Correlation ID Injector
├── modules/                             # Domain Business Modules
│   ├── auth/                            # User Identity & Token Management
│   │   ├── auth.controller.ts           # Express Login, Register & Logout Handlers
│   │   ├── auth.routes.ts               # Auth Endpoint Definitions
│   │   ├── auth.validator.ts            # Zod Schema Request Validation
│   │   ├── middleware/auth.middleware.ts   # JWT Bearer Token Verification Guard
│   │   ├── providers/bcrypt.provider.ts # Password Hashing Provider
│   │   ├── repositories/user.repository.ts # Prisma User Table Data Access
│   │   └── services/token.service.ts    # SHA-256 Token Rotation Service
│   ├── contest/                         # Timed Competitions & Scoring Engine
│   │   ├── contest.controller.ts        # Contest CRUD & Problem Fetching
│   │   ├── contest.routes.ts            # Contest API Routes
│   │   ├── gateways/contest.gateway.ts   # Socket.io Live Score Publisher
│   │   ├── repositories/contest.repository.ts # Prisma Contest Table Queries
│   │   └── services/scoring.service.ts  # ICPC Time Penalty Calculation
│   ├── operations/                      # Admin Dashboard & Moderation
│   │   ├── operations.controller.ts     # System Metrics & User Ban Handlers
│   │   └── services/rbac.service.ts     # Dynamic Permission Group Validator
│   ├── problem/                         # Practice Problem & Test Case CRUD
│   │   ├── problem.controller.ts        # Question Bank Query Handlers
│   │   ├── problem.routes.ts            # Problem Endpoints
