# public/models — 3D Model Assets

## ⚠️ MacBook GLB Model Required

Place your MacBook GLB file here as:

```
public/models/macbook.glb
```

### Model Requirements

The laptop model should include:
- Premium MacBook-style design
- PBR materials (metallic aluminum body)
- Screen mesh named one of: `screen`, `Screen`, `display`, `Display`, `lid`, `Lid`, `glass`, `Glass`
- Realistic proportions (~2.8 units wide, ~1.8 units deep)

### Recommended Sources (Free, CC0)

1. **pmndrs market** (used in official drei examples):
   https://market.pmnd.rs/model/macbook

2. **Sketchfab** (filter by CC0 license):
   https://sketchfab.com/search?q=macbook&licenses=7c23a1ba4ed44fb686a5134eca6ae73e

3. **Three.js Journey / Official drei examples**:
   The model at `vazxmixjsiawhamofees.supabase.co/storage/v1/object/public/models/macbook/model.gltf`
   can be downloaded and placed here.

### Without the model

The app still works — it renders a detailed primitive-geometry laptop
with full animations, RenderTexture screen, and all lighting effects.

No code changes are required after placing the file here.
